# qatrol.github.io

Личный сайт-визитка на Vite. Пять полноэкранных слайдов на десктопе, обычная
вертикальная страница на телефоне. Сборка статическая, хостинг — GitHub Pages,
деплой идёт из `.github/workflows/deploy.yml` при пуше в `main`.

## Запуск

```bash
npm ci
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview  # проверить собранную версию
```

## Структура

```
index.html            разметка слайдов, метатеги, окно терминала
src/
  main.js             точка входа: подключает стили, запускает модули
  content.js          тексты и данные (направления, проекты, этапы, стек)
  icons.js            SVG-иконки как доверенные литералы
  render.js           сборка карточек и списков через DOM API
  slides.js           слайдер десктопа: wheel, клавиатура, точки, инерция
  terminal.js         фейковый терминал: команды, история, фокус-ловушка
  interactions.js     magnetic-кнопки, тень шапки, счётчик
  lib/dom.js          помощники create / createText / createSvg
  styles/
    tokens.css        палитра, шрифты, размеры, тайминги
    base.css          сброс, базовая типографика, фокус, skip-link
    layout.css        шапка, слайдер, точки, подвал
    sections.css      первый экран, заголовки секций, процесс, контакты
    components.css    прелоадер, кнопки, карточки, проекты, терминал
    motion.css        появление элементов, prefers-reduced-motion
    responsive.css    все медиазапросы, от широких к узким
```

Порядок в `main.js` обязателен: `responsive.css` должен идти последним, иначе
его правила перебьют базовые.

## Правила, которые здесь важны

**Текст только через `textContent`.** В `render.js` нет ни одного `innerHTML`.
Единственное исключение — `createSvg` в `lib/dom.js`, куда попадают иконки из
`icons.js`. Это литералы в репозитории, внешних данных там нет.

**Слайды изолированы.** Неактивные слайды получают атрибут `inert`: Tab не
уводит фокус за экран, а скринридер не читает всю страницу разом.

**Контент выше экрана.** `.slide` использует `justify-content: safe center` и
скроллится сам. `slides.js` отдаёт колесо и стрелки браузеру, пока слайд не
доскроллен до края, и только потом переключает слайд. Декор (свечение, пятно
на «Процессе») лежит в `.slide__decor` с `overflow: hidden` — иначе абсолютный
элемент попадает в scrollable overflow и добавляет пустую прокрутку туда, где
всё влезло.

**Клавиши не отбираются у ввода.** Обработчик `keydown` в `slides.js`
игнорирует события из полей ввода, из открытого диалога, с модификаторами, а
пробел на кнопках и ссылках отдаёт браузеру как активацию.

**Слайдер включается и выключается на лету.** Слушатели вешаются один раз и
проверяют флаг `deckActive`. Переход через 900px в любую сторону — сужение
окна, расширение из мобильного вида, поворот планшета — пересобирает режим
без перезагрузки. На мобилке ни колесо, ни стрелки, ни свайп ничего не
перехватывают.

**Стили не через `@import`.** Vite в dev-режиме резолвит `@import` внутри CSS
от корня проекта и падает с 500. Поэтому все файлы подключаются из `main.js`.

## Как править контент

Тексты, карточки направлений и проекты лежат в `src/content.js`. Разметки там
нет — только данные. Чтобы добавить проект, допишите объект в массив
`projects`. Поле `href` необязательное: без него название рендерится текстом,
без ссылки.

Иконки — `src/icons.js`, ключ подставляется в поле `icon` карточки. Если ключа
нет, берётся `plus`.
